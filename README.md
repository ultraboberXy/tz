# Sub App — демо-приложение с онбордингом и подпиской

Простое Flutter-приложение, демонстрирующее поток онбординга, экран выбора подписки (Paywall) и главный экран с контентом. Статус подписки эмулируется через `SharedPreferences` — реальный биллинг не требуется.

## Основные функции

- **Онбординг (1–2 экрана)**  
  Пара информативных страниц с иконкой, заголовком и описанием. Кнопка «Продолжить» переводит на Paywall.

- **Paywall**  
  Выбор между месячной и годовой подпиской (год — со скидкой 44%). Кнопка «Продолжить» эмулирует покупку и открывает главный экран.

- **Главный экран**  
  Контент для подписчиков: приветствие, новости, полезные советы и цитата дня.

- **Сохранение состояния**  
  После «покупки» статус подписки сохраняется локально. При следующем запуске приложение сразу показывает главный экран, минуя онбординг и Paywall.

## Технологии

- [Flutter](https://flutter.dev) (Dart)
- [shared_preferences](https://pub.dev/packages/shared_preferences) — для хранения статуса подписки

## Структура проекта
lib/

├── screens/

## Установка и запуск

1. Убедитесь, что у вас установлен Flutter. Инструкции: [flutter.dev/docs/get-started/install](https://flutter.dev/docs/get-started/install)
2. Клонируйте репозиторий:
   git clone <ваш-репозиторий>
   cd sub_app
Установите зависимости:
flutter pub get
Запустите приложение на подключённом устройстве или эмуляторе:
flutter run
